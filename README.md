# 古诗插画提示词 · 74 首

为小学古诗词背诵（6 岁古诗带背计划，74 首）逐首编写的 **AI 绘画提示词**。每份提示词用于生成一张「中国传统水墨意境 × 温润水彩绘本」风格的古诗教材插画，作为孩子理解诗意、背诵诗句的**视觉记忆锚点**——看到画面想起诗句，看到注释理解关键词，按画面中的人物动作和景物顺序自然背出整首诗。

## 每份提示词的结构

| 段落 | 内容 |
|---|---|
| 【一】古诗信息 | 诗名、朝代作者、逐字诗句、意境五要素（季节；时间；天气；情感；氛围） |
| 【二~四】固定规范 | 核心创作目标、水墨×水彩绘画风格、横版 4:3 教材排版 |
| 【五】词语注释 | 3~4 个难词的极短释义（如 蓑衣＝草或棕编成的雨衣），画面内轻量标注 |
| 【六】逐句画面 | 每句一条具体画面设计：人物动作、位置（近/中/远景）、环境细节 |
| 【七~八】约束 | 内容准确性与数量约束、负面约束（禁错字/现代物品/卡通化等） |

## 使用方法

1. 在 `prompts/` 打开对应诗的文件，**整份复制**；
2. 粘贴给 AI 绘图模型（GPT-4o / Midjourney / 即梦 / 通义万相等），生成横版 4:3 插画；
3. 插画可打印成卡片：一面图、一面诗，配合每日背诵使用。

> 提示：不同模型对画面内文字（诗题、诗句、注释）的渲染能力差异较大，文字出错时优先选支持中文文字渲染的模型，或出图后用排版工具自行叠加文字。

## 数据与校验

- 诗文本取自本机「古诗计划」项目 `scripts/data_poems.py`（部编版/通行版本，74 首），生成时由程序从源数据逐字复制，并经独立脚本校验：**74 份文件诗句逐字一致、结构完整、无占位符残留、逐句画面引用逐字一致**。
- 生成规范见 [INSTRUCTIONS.md](INSTRUCTIONS.md)（模板骨架 + 意境/注释/逐句画面的写法与质量红线），可复用于扩充新的诗目。
